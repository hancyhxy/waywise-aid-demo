What changed from mid-fi
  1. “Add your first journey” empty state; From and To are the only required fields.
  2. Trips → Saved journeys, with Use / Edit / Add actions.
  3. Weekday scheduling is optional; skip or change a single date.
  4. Route-based names (“UTS → Chatswood”); custom names optional.
  5. Profile from the avatar: account sync, default preferences.
  6. Saved routes and return trips on Today, with a suggested journey.
  7. Separate scopes: today / saved journey / one date / recurring schedule.
  8. Tap a route or View details → Route details drawer → Start journey → In progress drawer (× collapses to a mini bar; End journey any time, with confirmation).
  9. Clear preference labels, “Select all that apply”, check marks.
  10. Today's choices vs saved defaults; explicit “Save as default”.
  11. More preferences: less waiting, predictable arrival, transport modes.
  12. Wait / Departs / Arrives shown separately.
  13. Consistent badges; active priorities emphasised with text.
  14. “Why this route?” with reasons, trade-offs and preference conflicts.
  15. “Arrival estimate confidence”, update times, operator vs prediction labels.
  16. Carriage-level crowding diagram with direction and update time.
  17. Compare alternatives from details and the active journey.
  18. Report carriage conditions, labelled as passenger reports.
  19. Share journey: arrival time once, or time-limited arrival updates.
