# Waywise — Mid-fidelity prototype

Same layout, content and working interactions as the v1 hi-fi demo (`../`), restyled to mid-fidelity: greyscale, system font, one blue accent for primary actions and selection, and muted red/green for status meaning only. No brand colours, shadows or decorative fills. `midfi.css` overrides `styles.css`; `index.html`/`app.js` are v1 copies.

Fidelity ladder: `../low-fi/` (wireframe) → `mid-fi/` (this) → `../` (v1 hi-fi) → `../v2/` (iteration).
Live: https://hancyhxy.github.io/waywise-aid-demo/mid-fi/
